## Findings

* **`*.workers.dev` edge protection rejects non-browser User-Agents.** A request to the
  deployed relay carrying `Python-urllib/3.12` gets `403 error code: 1010` from Cloudflare's
  edge **before the worker runs** (browser UA → `200 ok`, same request otherwise). Real
  clients (browsers on `github.io`) are unaffected; probing tooling must send a browser-like
  `User-Agent`. Documented in `relay/README.md` "Known caveats".
* **CF edge egress is friendlier than the sandbox's datacenter egress for ANDROID**: the W0.4
  sandbox matrix measured the ANDROID client as bot-walled from datacenter; through the
  deployed worker it resolves OK. The PO-free ladder remains the strategy; this just widens
  the working set.
* **The canary's split-traffic experiment now has both halves live**: relay-resolved
  innertube calls (datacenter CF IP) + direct-from-residential-browser media fetches.
